The demo includes features that allow you to try out the "Blend prompts" and "MIDI Input" functions shown in the first half of the video above.

## Download

You can download the demo project in EXE format from [here](https://github.com/Akiya-Research-Institute/MagentaRealtime2-Demo-UE5/releases).

## GitHub Source

The UE5 demo project files are available on [GitHub](https://github.com/Akiya-Research-Institute/MagentaRealtime2-Demo-UE5).

## Software Requirements

- Windows 64-bit
- Unreal Engine 5.8.0
- Magenta Realtime 2 Plugin for UE v1.0 or higher
- CUDA: 12.8.2
- cuDNN: 9.23

Please refer to [here](../install) for instructions on installing CUDA and cuDNN.

## Hardware Requirements

- NVIDIA GPU with CUDA Architecture 7.5 (RTX 2000 series) or later is required.
